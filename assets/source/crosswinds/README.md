# Crosswinds source art

Generated with the built-in imagegen tool for this project on the Crosswinds theme branch. Original outputs are retained without overwriting the earlier Ships source assets.

- `title.png`: 5:3 black-ink literary maritime frontispiece; runtime title and button are drawn separately.
- `encounters.png`: four columns × three rows; kind order matches `encounter_content.h`.
- `regions.png`: three columns × two rows; order matches `REGION_NAMES`.

`tools/assets/build_generated_art_x4.py` crops the regular grids, fits their subjects to native dimensions, thresholds to one-bit ink and records asset hashes. These are original allusive compositions, not reproductions of book illustrations.
